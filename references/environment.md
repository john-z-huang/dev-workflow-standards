# Git 写操作与 Codex 审批

固定 Git/GitHub 操作由 MCP 专用工具执行。Codex MCP 配置使用 `default_tools_approval_mode="writes"`，让写工具在执行前进入 Codex 审批流程。工具审批与 Skill 中要求的用户意图授权是两个独立前置条件；没有相应授权，不调用写工具。

不以终端命令代替受支持的工具，也不在拒绝后尝试更换路径、通用执行器或其他方式绕过审批。工具因权限、脏工作区、状态冲突、远端状态或能力范围而停止时，保留现场，说明已完成的步骤、失败原因和缺少的条件。

本服务没有暂存、提交、任意命令或项目自定义测试工具。它可通过 `check_staged_changes(repo_path)` 检查暂存区空白问题；是否运行项目测试按项目要求和用户指示处理。
