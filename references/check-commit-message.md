# Commit message 检查

## 功能描述

`scripts/check-commit-message.py` 检查 Git 提交信息的三个可明确判定项：

- 提交标题必须使用 `<type>: 中文说明` 格式，其中 `type` 必须是 `feat`、`fix`、`docs`、`refactor`、`test`、`chore`、`perf`、`build` 或 `ci`；
- 提交主题必须包含中文说明；
- 禁止 `Generated with`、`Generated by`、`Created with`、`Co-Authored-By` 等工具署名或生成声明。

脚本只检查署名/生成声明上下文，不会禁止所有产品名字符串，以免误拦截合法的技术说明或本 Skill 自身的规则文档。

## 触发时机

- 推荐作为标准 Git `commit-msg` hook，在提交信息最终写入前触发。
- `commit-msg` 属于 `git commit` 流程；该检查不会延迟到向 remote 仓库执行 `git push` 时。
- 也可以手动传入提交信息文件或 `--message` 文本检查。

## 手动执行

```bash
python3 scripts/check-commit-message.py .git/COMMIT_EDITMSG
python3 scripts/check-commit-message.py --message 'feat: 增加输入校验'
```

## 边界

脚本只检查提交信息文本，不检查分支、暂存区或提交内容，也不安装 Git Hook。提交是否属于单一模块由上层流程判断。

## 退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 提交信息通过检查 |
| 1 | 提交信息违反格式、语言或署名约束 |
| 2 | 参数错误或无法读取提交信息 |
