# Commit message 检查

使用 `check_commit_message(message)` 校验提交信息标题：必须符合 `<type>: 中文说明`，类型限于 `feat`、`fix`、`docs`、`refactor`、`test`、`chore`、`perf`、`build` 或 `ci`；标题需含中文说明；禁止 `Generated with`、`Generated by`、`Created with`、`Co-Authored-By` 等工具署名或生成声明。

检查只分析提供的文本，不读取或修改 Git，也不检查分支、暂存区或提交内容。它只检查署名/生成声明上下文，不屏蔽所有产品名字符串，以免误拦截合法技术说明或规则文档。

推荐通过项目的 `commit-msg` Hook 自动执行。Hook 脚本可以调用仓库中的兼容脚本；交互式 Skill 工作流使用 MCP 工具。
